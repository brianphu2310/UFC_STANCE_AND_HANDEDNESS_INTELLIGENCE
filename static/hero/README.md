# Page banner photos

Each page opens on a photo banner. Drop one image per page here, named after the page:

`overview`, `explorer`, `build-a-fighter`, `stance-lab`, `spar-vs-brian`, `data` (`.jpg`, `.png` or `.webp`)

A page with no photo of its own uses `default.*`, a render of the app's own 3D fighters.
Wide photos work best (about 1400 × 400). The title sits over the left side, which the banner
darkens, so put the fighters on the right. Credit each photo in `credits.csv` (`key,credit`).
