# Source-to-Target Mapping

Maps `data/ufc_fighters_enriched.csv` (117 rows) to the star schema built by `python -m pipeline.run`
(`pipeline/extract.py` -> `validate.py` -> `transform.py` -> `load.py`). Model: [DATA_MODEL.md](DATA_MODEL.md). Column meanings: [DATA_DICTIONARY.md](DATA_DICTIONARY.md).

## Dimensions

| Source column(s) | Target | Rule |
|---|---|---|
| `fighter` | `dim_fighter.fighter_name` | Trim; business key (UNIQUE). Rows ordered by accent/case-normalised name (`scripts.build_clean_dataset.norm`) before assigning surrogate `fighter_key`, so keys do not depend on spelling variants. |
| `gender` | `dim_fighter.gender` | Must be `Men` or `Women`. |
| `dob` | `dim_fighter.dob` | Parsed to date, stored ISO `YYYY-MM-DD`. |
| `ufcstats_url` | `dim_fighter.ufcstats_url` | As given. |
| `champion` | `dim_fighter.is_champion` | Cast to 0/1; curated flag. |
| `active` | `dim_fighter.is_active` | True/False -> 1/0; nullable. |
| `stance_project`, `weight_class_source`, `learning_tip` | same names in `dim_fighter` | As given. |
| `stance` | `dim_stance.stance` | Distinct; must be Orthodox, Southpaw or Switch. |
| `hand` | `dim_handedness.hand` | Distinct; must be Right or Left. |
| `weight_class`, `gender` | `dim_weight_class` | Distinct pair; a weight class is gendered. |
| `country`, `continent` | `dim_country` | Distinct pair. |
| `fighting_style` | `dim_fighting_style.fighting_style` | Distinct; Striker, Grappler, All-rounder or Not enough UFC data. |

## `fact_fighter_record` (one row per fighter)

| Source column | Target column | Rule |
|---|---|---|
| (lookups) | `stance_key`, `hand_key`, `weight_class_key`, `country_key`, `style_key` | Joined to the dimensions above (`validate="m:1"`, so a missing or duplicate key fails the build). |
| `wins`, `losses`, `total_fights` | same | `total_fights = wins + losses` enforced by a CHECK. |
| `win_rate` | `win_rate` | 0-100. |
| `height_cm`, `reach_cm`, `ape_index_cm` | same | Nullable. |
| `age` | `age_years` | Renamed. |
| `popularity_index` | `popularity_index` | 0-100. |

## `fact_ufc_performance` (0..1 row per fighter)

Loaded only for fighters where `ufc_fights` is not null. Columns map one-to-one from the CSV: `ufc_fights`, `ufc_wins`, `ufc_losses`, `ufc_ko_wins`, `ufc_sub_wins`, `ufc_dec_wins`, `title_fights`, `main_events`, `stats_fights` (cast to nullable int), `first_ufc_fight`, `last_ufc_fight`, `ufc_minutes`, `slpm`, `str_acc`, `sapm`, `str_def`, `td_avg`, `td_acc`, `td_def`, `sub_avg`, `kd_avg`, `ctrl_pct`, `pct_distance`, `pct_clinch`, `pct_ground`, `pct_head`, `pct_body`, `pct_leg`, `striking_index`, `grappling_index`.

## Deliberately not loaded

| Source column | Why |
|---|---|
| `foot`, `foot_hand` | Generated by a seeded random rule in `scripts/enrich_dataset.py` (marked `estimated` in `data/data_dictionary.csv`), so they are not observations. Listed in `EXCLUDED_ESTIMATED_COLUMNS`. |
| Other enrichment columns not listed above | Remain in the CSV for the Streamlit app; the warehouse carries only the columns in this document. |

## Load order and audit

`dim_*` -> `dim_fighter` -> `fact_fighter_record` -> `fact_ufc_performance`. Row counts per table are written to `etl_load_audit`; validation results are in [DATA_QUALITY.md](DATA_QUALITY.md).
