# Data dictionary

Column-level reference for `data/ufc_fighters_enriched.csv` (117 rows, 62 columns), the file the
Streamlit app and the warehouse pipeline read. The short, grouped version is
[`data/data_dictionary.csv`](../data/data_dictionary.csv); this page lists every column, with its
type, where it comes from in this repo, and where it lands in `warehouse.db`.

**Provenance legend** (from `data/data_dictionary.csv` and the build scripts)
`scraped` = taken from a source dataset; `derived` = computed from other columns by a formula in
`scripts/`; `curated` = assigned by hand in a script; `estimated` = generated by a rule plus seeded
random noise, **not real data** (dominant foot only).

## Where the data comes from, as far as the repo shows

- `scripts/build_clean_dataset.py` builds `data/ufc_fighters_clean.csv` from (a) `UFC_FINAL_DATASET.xlsx`
  (the project's 117 fighters with record, stance, dominant hand; the script's docstring attributes
  the dominant hand to Tapology), (b) `ufc_data.csv` (weight class and learning tip) and (c) a clone of the
  public GitHub repository `Greco1899/scrape_ufc_stats` (UFCSTATS tale-of-the-tape and fight-level
  results), downloaded into `data/raw/` (git-ignored).
- `scripts/enrich_dataset.py` adds `stance`, `foot` (estimated), `champion` (curated list),
  `popularity_index`, label columns and writes `ufc_fighters_enriched.csv`.
- `notebooks/UFC_DATA_SCRAPING.ipynb` is an earlier scraping notebook. Reading its code, it requests
  `http://ufcstats.com/statistics/fighters` (five index pages) and individual fighter pages with
  `requests` + BeautifulSoup, pausing 1 second between index pages. It does not reference Tapology or
  Sherdog, and it does not read `robots.txt` or set a User-Agent. Anyone re-running it should first
  check UFCStats' terms of use and `robots.txt` and keep the request rate low. The pipeline in this
  repo does not scrape anything: it only reads the CSVs committed under `data/`.
- Curated or hand-entered columns (`champion`, `weight_class` corrections, the sample
  coaches and classes) are not scraped and should not be described as such.

## Known data caveats

- 43 of 117 fighters have a different stance in the project Excel (`stance_project`) than in UFCSTATS
  (`stance`). The app and warehouse use the UFCSTATS value. Results that depend on stance (for
  example the README's Key Findings, which were written earlier) can therefore differ from the
  warehouse queries in `docs/query_results/`.
- The 117 fighters are a curated set, not a random sample of UFC fighters.
- `age` and `active` depend on the date the CSV was built and do not update on their own.
- `data/coaches_sample.csv` and `data/classes_sample.csv` are fictional samples (see
  `scripts/enrich_dataset.py`) and are not part of the warehouse.
